# Security Policy

ScopeHound is a community-maintained security research and attack-surface discovery tool. We welcome responsible reports of vulnerabilities in ScopeHound itself.

## Supported versions

Security fixes are prioritized for the latest code on the `main` branch. Older releases and forks are not guaranteed to receive fixes.

## Reporting a vulnerability

**Please do not open a public GitHub issue or discussion for an undisclosed vulnerability.**

Use GitHub's private vulnerability reporting feature:

1. Open [ScopeHound Security Advisories](https://github.com/jmateocarbon/scope-hound/security/advisories).
2. Select **Report a vulnerability** (available when private vulnerability reporting is enabled).
3. Include a description of the issue, its impact, affected code or versions, reproduction steps, and a minimal proof of concept, if possible.

If private vulnerability reporting is not available, contact the maintainer at **johnmatthew.carbon@gmail.com** with the subject `ScopeHound security report`. Avoid sending credentials, personal data, or live exploitation results in an unencrypted email. Ask for a secure exchange method if sensitive materials are needed.

## Disclosure and response

The maintainer will review incoming reports, attempt to reproduce them, and coordinate a fix and disclosure when appropriate. As a volunteer-maintained project, response and remediation times are not guaranteed.

Please give the maintainer a reasonable opportunity to investigate and remediate an issue before public disclosure.

## Scope of this policy

This policy covers vulnerabilities in ScopeHound source code, its published workflows, and project-maintained distribution artifacts. Vulnerabilities in third-party sites or services discovered with ScopeHound should be reported to their respective owners, not to this project.

Only test systems you own or have explicit permission to assess. Avoid destructive testing, service disruption, credential harvesting, or accessing third-party information.

For general feature requests or non-sensitive bugs, use [GitHub Issues](https://github.com/jmateocarbon/scope-hound/issues).
